# Rebootworthy Touch Dashboard

**Old Tech. New Purpose.**

Rebootworthy Touch Dashboard is a lightweight, customizable touchscreen dashboard designed to give older tablets, touchscreens, and browser-capable hardware a useful second life.

The project uses only **HTML, CSS, and JavaScript**. No database, cloud account, framework, or internet connection is required.

## Why This Exists

Old tablets and touchscreen devices are often still perfectly capable of displaying a simple web interface.

Instead of throwing them away, Rebootworthy Touch Dashboard turns them into customizable displays for homelabs, workshops, workouts, smart-home controls, media systems, family dashboards, network monitoring, or anything else you want to build.

The goal is to provide a **blank canvas**, not force a specific use case.

## Features

- Lightweight HTML/CSS/JavaScript
- Designed for older hardware
- Touch-friendly interface
- Responsive layout
- Fullscreen support
- Configurable branding
- Configurable tiles
- Shared page template
- No database required
- No cloud account required
- No external API required
- Works entirely on a local network
- Easy to self-host
